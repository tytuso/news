# Nile AI Signal

**AI intelligence without the noise.**

Nile AI Signal is being built by Nile AI Solutions as an AI intelligence network for founders, developers, investors and businesses in Africa and beyond.

## V1

The first version:

- monitors official AI sources
- refreshes the live signal feed every 15 minutes
- de-duplicates stories
- classifies updates into models, products, research, business, developers and safety
- ranks likely impact
- explains why an update matters
- detects an Africa angle
- always links to the original source

Initial official sources:

- OpenAI News
- Google DeepMind
- Hugging Face
- GitHub Changelog

## Product direction

V2 will add more company, research, startup and African technology sources plus cross-source verification.

V3 will add AI-generated intelligence briefs, personal feeds, alerts and search across historical signals.

V4 will add automatic email, Telegram, WhatsApp channel and social publishing workflows plus Pro and Team intelligence products.

## Development

```bash
npm install
npm run dev
```

Environment variables are not required for the V1 public feed. AI enrichment and distribution credentials will be added in later phases.
