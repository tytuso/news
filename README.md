# NileSignal — AI news without the noise

NileSignal is a mobile-first AI news reader from Nile AI Solutions, using Next.js and public RSS/Atom feeds. No accounts, paid AI model API, or database are required.

## Features
- 20 configured feeds covering AI labs, research, products, developer tools, global reporting and African technology publishers
- Per-publisher error isolation, 75-day age limit, RSS normalization and duplicate headline detection
- Automated category filters and impact explanations (rules-based, not fact-checked or generated by a paid AI model)
- Search, publisher filter, impact sorting, save-to-device bookmarks, mobile sharing, light/dark theme, installable PWA
- JSON at /api/feed, RSS at /api/rss and feed status at /api/health
- Branded social sharing image and responsive layout

## Reliability
The aggregated news snapshot is cached for 15 minutes; fresh data is loaded on demand when people visit. This is not a background process that fires every 15 minutes. Each provider can fail independently. /api/health reports healthy, degraded or unhealthy and details which sources have recent articles. Every six hours, a GitHub Actions workflow checks the Vercel production alias and creates one incident issue on repeated failures.

## Editorial note
Publisher descriptions are based on RSS metadata. Categories, highlights, and "why it matters" labels are rule-based estimates, not independent fact checks, investment advice or complete real-time AI industry coverage. Sources can be unreachable, blocked or stale; consult source status and publisher pages.
